# Logic Puzzle Generator

Logic Puzzle Generator is a Python application that creates random riddles and logical challenges from a collection of templates.

Instead of storing complete puzzles, the generator combines objects, names, numbers and rules to produce unique variations each time it runs.

## Features

- Random puzzle generation
- Multiple categories
- Difficulty levels
- Puzzle statistics
- Export generated puzzles

## Categories

- Logic
- Numbers
- Objects
- Detective
- Pattern Recognition

## Example

```
Category

Logic

Difficulty

Medium

Puzzle

Three travelers each own one colored backpack:
red, blue and green.

Anna does not own the red backpack.
The blue backpack belongs to someone taller than Ben.
Chris is not carrying the green backpack.

Who owns each backpack?
```

Run

```bash
python main.py
```
